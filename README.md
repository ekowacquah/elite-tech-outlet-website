# Elite Tech Outlet — Website Project

Four linked HTML pages for Tech Foundations CIS (CIDM-6303).

## Open the website

Open `index.html` in a web browser. No installation, build step, account, or internet connection is needed. Keep the HTML files, `styles.css`, `script.js`, and `assets` folder together.

## Pages

- `index.html`: Home, category links, and introduction.
- `products.html`: Sample catalog with category filters and search.
- `about.html`: Business concept, device selection guidance, and project context.
- `contact.html`: Validated demo inquiry form and expandable FAQs.

## Features

Responsive layouts, mobile navigation, semantic HTML, active-page indicators, keyboard focus styles, skip link, image descriptions, accessible form labels, product search, category filters, and downloadable inquiry drafts. Core page navigation and content remain available without JavaScript. Form generation and product filtering require JavaScript.

## Demo limitations

The catalog represents illustrative product categories, not live inventory. There are no online sales, invented reviews, or claimed business guarantees. The form creates a local text file and does not send, store, or submit user details to a business.

## AI assistance and original assets

An OpenAI AI coding agent helped generate and refine the HTML, CSS, JavaScript, and SVG illustrations. The device illustrations are original project graphics and use no external image files, fonts, libraries, or services. Review and personalize the code before submission.

## Publish your code to GitHub (preferred submission)

1. Sign in to your GitHub account.
2. Create a repository named `elite-tech-outlet-website`. Select **Public** so the grader can view the code.
3. Extract the ZIP archive on your computer.
4. In the new repository, choose **Add file → Upload files**. Upload the extracted website files and the entire `assets` folder. Upload the contents, not the ZIP file. Ensure `index.html` is at the repository root.
5. Commit the files.
6. Open the repository link while signed out or in a private browser window to confirm it is public.
7. Submit the repository URL on WTClass. The URL format is `https://github.com/YOUR-USERNAME/elite-tech-outlet-website`; substitute your actual username. Do not submit this placeholder.

Optional live GitHub Pages site: open the repository's **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. After deployment, GitHub displays the live site link. Submit the repository URL required by the instructor even if you also share the live link.

## ZIP fallback

The assignment allows direct ZIP upload to WTClass if you experience technical difficulties accessing GitHub. Use `Elite_Tech_Outlet_Website.zip` for that fallback. The separately hosted preview is for reviewing the site and is not the public GitHub repository required by the assignment.
