Are these real Apple models?

Yes. Each catalog entry lists a real model and links to Apple’s official specifications. This class project does not display live inventory or prices.

Can I order through this website?

This website is an inquiry-based class project. It has no checkout, payment processing, or order fulfillment.

What should I confirm for a renewed device?

Ask about battery condition, cosmetic grade, carrier status, storage, included accessories, and return or warranty terms. These details vary by device and seller.

What should a wholesale inquiry include?

Include model names, quantities, preferred storage, acceptable condition, and timing. Confirm availability and written terms before committing to a purchase.
